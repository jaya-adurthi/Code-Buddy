**Code Buddy** is an interactive AI-powered coding assistant designed to help students and developers write, understand, and debug code efficiently.

📁 **GitHub Repository**: [https://github.com/jaya-adurthi/Code-Buddy](https://github.com/jaya-adurthi/Code-Buddy)

---

## ✨ Key Capabilities

- 🤖 **Code Generation**: Generates clean, well-documented code snippets based on natural language prompts.
- 💡 **Code Explanation**: Explains complex algorithms, syntax structures, and programming concepts step-by-step.
- 🐛 **Code Debugging**: Identifies syntax errors, runtime bugs, and logical flaws, providing actionable fix recommendations.
- 📚 **Programming Guidance**: Assists students with computer science concepts, best practices, and code refactoring.

## 🛠️ Tech Stack

- **Core Language**: Python

## 💻 Local Setup & Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/jaya-adurthi/Code-Buddy.git
   cd Code-Buddy
   ```

2. **Create a Virtual Environment**
   ```bash
   python -m venv venv
   # On Windows
   venv\Scripts\activate
   # On macOS/Linux
   source venv/bin/activate
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Streamlit Application**
   ```bash
   streamlit run app.py
   ```
